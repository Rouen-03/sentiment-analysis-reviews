# Sentiment Analysis of Product Reviews

Classifying Amazon product reviews into positive, negative and neutral sentiment
using TF-IDF features and classical machine learning models, deployed as an
interactive Streamlit web application.

## Tech stack
- Python, NLTK, scikit-learn, pandas, numpy
- matplotlib / seaborn / wordcloud for visualisation
- Streamlit for the web app
- Git & GitHub for version control

## Project structure
- notebooks/ - analysis notebooks (cleaning, EDA, preprocessing, modelling)
- app/ - streamlit application
- data/ - raw and processed datasets (not tracked in git)
- models/ - trained model files
- plots/ - generated figures
